# Architecture

- Frontend Next.js App Router with role-aware dashboard composition.
- Backend NestJS layered modules with JWT + RBAC, provider adapters, queue workers, and websockets.
- AI FastAPI microservice for anomaly detection, trend forecast, and risk scoring.
- PostgreSQL with Prisma; Redis cache + BullMQ jobs.
- Nginx ingress and Docker Compose for local production-like topology.
